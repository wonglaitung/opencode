# 银行专项：交易安全与灾备（单位覆盖层，可选启用）

> 本文件为银行业需求发起单位的覆盖层规约，置于部署项目的 `conventions/reqdoc/` 下由插件与基线合并注入；
> 非插件基线、不随插件分发，按单位需要启用或移除。

## 1. 幂等与防重

资金类操作须定义幂等键与防重复提交/防并发双提交机制；明确网络超时、部分成功、重复请求的判定与处理，避免重复记账。

## 2. 冲正、撤销与对账

明确逆向操作（冲正/撤销/退票/拒付/退款）的触发条件与会计处理；日终或准实时对账机制、差错处理（长款/短款）与人工干预路径须交代清楚。

## 3. 清算与最终性

跨系统/跨机构资金往来须声明清算模式、清算周期与最终性时点；明确清算未完成时的在途交易状态与风险控制。

## 4. 灾备与可用性

须给出灾备目标：RTO/RPO、两地三中心切换条件与演练要求；明确故障切换时数据一致性与在途交易处理。
