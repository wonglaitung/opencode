# reqdoc 异常分类规约

## 1. 异常须区分三类

- 业务异常：规则不允许，如余额不足、超过额度、黑名单拦截；
- 系统异常：技术故障，如超时、服务不可用、幂等冲突；
- 外部机构/通道异常：人行/银联/CIPS/SWIFT/第三方支付等外部返回失败、合作行拒付、通道超时。
三类须分别描述，不可笼统归为"调用失败"。

## 2. 每类异常给处理预期

说明触发条件、谁来处理、用户看到什么提示。用户提示须合规：不泄露系统内部细节、不暴露账户/卡号等敏感信息，仅给可理解的处理引导。

## 3. 边界与兜底

明确未覆盖情形的兜底处理，不遗留「其他」空泛表述。
