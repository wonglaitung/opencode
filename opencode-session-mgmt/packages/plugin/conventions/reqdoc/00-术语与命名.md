# reqdoc 术语与命名规约

## 1. 术语须引用原文

涉及制度/规范/监管原文的术语，定义时引用原文出处，不凭记忆改写。

## 2. 命名见名知意

功能点、字段、角色命名使用业务通用称谓。区分两类缩写：行业通用标准缩写（如 AML/KYC、CIPS、SWIFT、银承、大小额）属正常行话，允许使用；仅禁止"内部黑话"（团队自造、外人难懂的拼音缩写或代称）。

## 3. 一词一义

同一概念全文统一术语，不混用近义词。

## 4. 监管口径与系统口径映射

涉及监管术语（如"个人金融信息""客户身份识别"）与系统内部称谓（如"客户信息""KYC"）不一致时，显式建立映射表，避免监管口径与系统口径混用导致歧义。
