# websec 测试纪律

- 只测试已授权目标：目标、环境、账号、时间窗、限速、停止条件必须记录在 scope 中。
- 默认只读（GET/HEAD/OPTIONS）。写操作、删除、批量提交、爆破、越权写、上传利用须开发者逐次确认，未授权一律不做。
- 发现越界、真实数据影响、触发告警或可能影响可用性时立即停止并回报，不继续探测。
- 证据只存本地索引（URL/方法/身份/时间/哈希/本地路径）。不把请求/响应正文、Cookie、令牌或用户数据发到上游。
- 没有请求/响应与复现步骤的结论只能标 suspected，不得标 confirmed；不把猜测写成漏洞。
- 报告中敏感字段脱敏；不导出真实用户数据，不保留生产口令。
