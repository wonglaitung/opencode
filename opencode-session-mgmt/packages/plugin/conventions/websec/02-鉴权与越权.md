# 鉴权与越权检查

- 先列角色矩阵：未登录、普通用户、只读用户、管理员（按 scope 实际账号）。
- 未授权访问：优先对 Edge 已捕获的 GET/HEAD 端点做无 Cookie 匿名只读探测（`websec_anonymous_probe`）；不需要用户退出登录重走完整页面。对比状态码、响应长度与关键字段。
- IDOR 读：替换资源 id/编号，确认是否返回他人数据；只读验证，不修改、不删除。
- 越权至少需要两个身份对照；只有一个身份时标 suspected，并说明缺少哪个对照身份。
- 每个入口的 authn/authz 类别都要收口；没有账号或端点不适用时标 not_applicable 并写理由。
- 越权测试流程：普通/低权账号操作 → `capture(phase=baseline)` → `switch_identity` → 高权账号重新登录并走同样流程 → `capture(phase=privileged)` → `websec_authz_compare`。切换后不得沿用上一个账号的 Cookie。
- 关注前端隐藏但后端未校验的操作；记录请求与响应证据后再下结论。
- 写接口无鉴权时，先在报告中说明风险；只有开发者逐次授权后才用 `websec_write_probe` 做单次可丢弃验证，禁止 DELETE/批量。
