# 资产与接口枚举

- 必须接管已登录会话：启动 Edge，让用户在 Edge 中登录并走完页面/操作流程；不要用 curl 或源码静态检查替代用户走查。
- 每个入口记录：method、path、参数位置（query/body/header/path）、身份、触发方式、来源（static/runtime/manual）。
- 覆盖页面、XHR/fetch、表单、上传、导出、回调、调试端点；不越界爬取第三方域名。
- 进入本阶段前必须问「普通测试还是越权测试」并 `websec_edge_capture(start, mode=...)`；用户说「本次录入已完成」后 `capture`。普通测试单阶段，越权测试 baseline/privileged 两阶段。响应正文落项目内证据目录，对话只看摘要。
- 排除 logout、delete、付款、发信等破坏性或不可逆链接；只记录不触发。
- 所有页面、接口、证据正文和报告必须落在项目内 `websec-evidence/<sessionID>/`，禁止 `%TEMP%` 或项目外路径。
- 覆盖不到的模块与原因写入 limitations，作为报告的一部分。
