# sdlc 日志与可观测性规约

## 1. 不打敏感信息

日志禁记密码、令牌、PII；确需记录身份/卡号类字段时须掩码（如卡号仅留后 4 位、身份证号中间 8 位打码），不做明文落盘。

## 2. 结构化与级别

用结构化日志，按 debug/info/warn/error 区分；交易/请求追踪 ID 贯穿整条链路的日志与外部调用（便于审计、排障与对账），关键路径必须带追踪标识。

## 3. 适量

不过量刷日志（避免性能与噪声），也不缺失关键错误上下文。

> 设计稿须就以上各维度给出符合性结论（满足 / 部分满足 / 风险+缓解），作为「技术规范符合性自检」小节的一部分，随 design 阶段确认一并交由开发者确认。
