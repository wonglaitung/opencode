# sdlc 并发·资源·幂等规约

## 1. 资源释放

连接/文件句柄/锁等用后释放，优先自动管理机制，避免泄漏。

## 2. 避免竞态

共享状态的多线程/异步访问须同步保护；临界区内不做重 IO 或外部调用。

## 3. 写操作幂等

对外写接口/任务须可重复执行且结果一致，便于重试与补偿。幂等键由业务唯一键（交易号/订单号/流水号）派生并跨服务传递，不得用随机值或易变字段充当。

## 4. 重试带退避

调易失败外部依赖时，重试须指数退避且设上限，区分可重试与不可重试错误。

> 设计稿须就以上各维度给出符合性结论（满足 / 部分满足 / 风险+缓解），作为「技术规范符合性自检」小节的一部分，随 design 阶段确认一并交由开发者确认。
