# sdlc 输出格式规约

## 1. 讲结构时先给图

讲**五阶段流转、数据流、调用顺序、门禁在哪拦**时，先给图再讲文字。图用**代码块内的
ASCII 文本图**（框线 + 箭头），开发者终端直接可读。

**不用 ```mermaid**——CLI 不渲染 mermaid，只显示源码，开发者看到的是一坨没渲染的代码。

收口诊断与结论时不用图：一段结论配一个框，比直接说更难懂。

## 2. 一个概念一个名字

同一件事不要换称呼——换个说法时简短对齐一次（「下称 X」）再继续，别让开发者自己去猜
两句话说的是不是一回事。

既有别名在**代码注释里写清来源**，别让下一个读到的人猜两个名字是不是一回事。
