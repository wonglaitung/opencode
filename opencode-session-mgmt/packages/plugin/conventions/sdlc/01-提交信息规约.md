# sdlc 提交信息规约

## 1. 遵循 Conventional Commits

提交信息格式 `type(scope): 简述`，type ∈ {feat, fix, docs, refactor, test, chore}。

## 2. AI 编写代码须带 [AI] 标记

你（AI）在提交由你编写或修改的代码时，必须自动在标题末尾加 `[AI]`，例如 `feat(auth): 登录增加重试 [AI]`。标记由你自动添加，无需人类手工填写。

## 3. 人类编写部分不标 [AI]

人类独立编写/修改的部分不要加 `[AI]`；AI 仅辅助、最终决策在人的提交不标 `[AI]`。

## 4. 一次提交一件事

标题简述动作，正文补「为什么」而非「改了什么」。
